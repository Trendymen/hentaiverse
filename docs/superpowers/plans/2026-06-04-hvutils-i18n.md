# hvUtils.js 界面汉化 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `hvUtils.js` 的全部界面文本与设置项说明翻译为简体中文,术语对齐 HentaiVerse 中文社区习惯,且不破坏任何功能。

**Architecture:** 两阶段。阶段一以 `equip_chinese_2.js` 内联字典为主源、fandom 简体 wiki / ehwiki 补充缺失项,产出并定稿《HV 简体术语对照表》;阶段二据术语表直接替换 `hvUtils.js` 源码字符串字面量,**逻辑标识符保留英文**,按功能模块分批,每批用 vscode-mcp-server 查 diagnostics + 人工复查。

**Tech Stack:** 油猴 UserScript(原生 JS,无构建);chrome-devtools MCP(抓 fandom,绕 403);WebFetch(抓 ehwiki);vscode-mcp-server(diagnostics)。

> **版本管理说明**:当前目录**非 git 仓库**。如需版本管理,执行前先 `git init`,则各任务末尾的 commit 步骤生效;否则以 `hvUtils.js.bak` 备份 + 每批 diagnostics 作为安全网,commit 步骤跳过。

> **配套文档**:设计 `docs/superpowers/specs/2026-06-04-hvutils-i18n-design.md`;UI 提取底稿 `docs/hvutils-ui-strings.md`。

## 通用译法基准(B 类高频词 / 句式,保证全局一致)

执行阶段二时,以下通用词**统一**译法,避免同词多译:

| 英文 | 统一中文 | 英文 | 统一中文 |
|---|---|---|---|
| Save | 保存 | Close | 关闭 |
| Revert | 还原 | Default | 默认 |
| Delete | 删除 | New | 新建 |
| Edit | 编辑 | Update | 更新 |
| Run | 运行 | Set | 设置 |
| Search | 搜索 | Reply | 回复 |
| Return | 退回 | Clear | 清空 |
| All | 全部 | Send / SEND | 发送 |
| Sell | 出售 | Salvage | 分解 |
| Offer | 供奉 | Bid | 买价 |
| Ask | 卖价 | Calculate | 计算 |
| Loading... | 加载中… | Waiting... | 等待中… |
| Checking... | 检查中… | Updating... | 更新中… |
| Collapse / Expand | 折叠 / 展开 | Details | 详情 |
| Select All | 全选 | Item Prices | 物品价格 |
| Import from JSON / Export to JSON | 从 JSON 导入 / 导出为 JSON | Reset Database | 重置数据库 |

**confirm 句式模板**:`Are you sure that you wish to X?` → `确定要 X 吗?`;`...credits?` 的 `credits` 译「绅士币」(与 equip_chinese 字典一致,见术语表)。
**alert 句式**:`You do not have enough credits.` → `绅士币不足。`;`An error has occurred.` → `发生错误。`;`The ... is empty.` → `… 为空。`

> ⚠️ 保留所有 `${...}`、`\n`、HTML 标签与 `&lt;`/`&gt;`/`&amp;` 实体;只改文案,不改逻辑。
